# Java Swing 贪吃蛇

一个使用纯 Java Swing 编写的贪吃蛇小游戏，不依赖任何第三方图形库或游戏引擎。

## 功能

- 方向键 / `WASD` 双操作方式，带转向缓冲队列，快速连按也不会 180° 掉头撞到自己
- 吃到食物加 10 分并逐步加速，速度有上限
- 支持暂停 / 继续，游戏结束后一键重开，并记录本次运行的最高分
- 蛇头带随方向变化的眼睛，蛇身由亮到暗渐变
- 撞墙或撞到自己判定结束，食物只会生成在空白格上

## 环境要求

需要 **JDK 17 或更高版本**（用到了 `switch` 箭头语法）。开发环境为 Oracle OpenJDK 27。

## 运行

Windows 用户可以双击：

```text
build_snake_game.bat
```

脚本会自动编译到 `out` 目录并启动游戏。

也可以使用 JDK 手动编译运行：

```powershell
javac -encoding UTF-8 -d out SnakeGame.java
java -cp out SnakeGame
```

> 注意编译时要带 `-encoding UTF-8`，源码里有中文注释和中文界面文字，
> 在中文 Windows 上不带该参数会因为默认 GBK 编码而报错或乱码。

## 操作方式

- 方向键 / `WASD`：移动，在开始界面按下即开局
- `空格`：开始界面开局，运行中暂停 / 继续
- `回车`：游戏结束后重新开始
- 鼠标点击：开始 / 暂停 / 重开

提示：代码中已经调用 `enableInputMethods(false)` 关闭了输入法，
所以**中文输入法下 `WASD` 也能正常转向**，不需要像其他游戏那样手动切到英文输入法。

这其实是个很容易踩的坑：中文输入法会在操作系统层把字母键截走去做拼音组词，
按键事件根本送不到 Java 窗口，表现就是"绑定写了但按键没反应"，
而方向键不参与组词所以一直正常。禁用输入法即可根治。

## 可调参数

都集中在 `SnakeGame.java` 顶部的常量区：

| 常量 | 含义 | 默认值 |
| --- | --- | --- |
| `CELL_SIZE` | 每个格子的像素大小 | 25 |
| `COLS` / `ROWS` | 棋盘横向 / 纵向格子数 | 28 / 22 |
| `INIT_DELAY` | 初始移动间隔（毫秒），越小越快 | 140 |
| `MIN_DELAY` | 速度上限对应的最小间隔（毫秒） | 60 |
| `SPEED_UP_STEP` | 每吃一个食物加快的毫秒数 | 4 |

## 实现说明

- 蛇身用 `ArrayDeque<Integer>` 存储，把坐标 `(x, y)` 编码成 `y * COLS + x` 的单个整数，入队出队都是 O(1)
- 游戏循环由 `javax.swing.Timer` 驱动，回调在 EDT 上执行，绘制线程安全
- 按键用 `InputMap` / `ActionMap`（`WHEN_IN_FOCUSED_WINDOW`）绑定，比 `KeyListener` 更可靠
- 自撞判定会排除即将移开的尾格，否则正常跟随尾巴移动会被误判为撞到自己
- 状态机：`READY` / `RUNNING` / `PAUSED` / `OVER`
